관리자 화면 비밀번호 사용법

1. 포트폴리오/js/admin.js 파일의 위쪽에서 다음 코드를 찾습니다.
   const ADMIN_PASSWORD = '1234';
   따옴표 안의 1234를 본인이 원하는 비밀번호로 바꾸고 저장하세요.
2. admin.html에 접속하거나 프리미어 페이지에서 Ctrl + Alt + E를 눌러 이동합니다.
3. 정한 비밀번호를 입력하고 [관리자 모드 열기]를 누르면 작품 추가·수정·삭제 화면이 표시됩니다.
4. 관리 후 [관리자 모드 잠그기] 버튼을 누르면 다시 비밀번호 입력 화면으로 돌아갑니다.

중요: 이 비밀번호는 웹페이지 화면을 숨기기 위한 간단한 잠금입니다.
공개 GitHub Pages의 JavaScript 소스를 보는 사람은 비밀번호를 알아낼 수 있으며,
개발자 도구로 잠금 화면도 우회할 수 있습니다. 따라서 다른 서비스에서 쓰는 비밀번호를 사용하지 마세요.
실제 GitHub 저장소에 작품을 올리려면 기존처럼 GitHub 토큰이 필요합니다.
토큰을 ADMIN_PASSWORD 자리에 넣거나 코드에 기록해서는 안 됩니다.

프리미어 포트폴리오 추가 관리자 안내

1. GitHub Pages의 /admin.html 주소로 이동하거나 premiere.html 페이지에서 Ctrl+Alt+E를 누릅니다.
2. GitHub 저장소의 소유자, 저장소 이름, 브랜치를 적습니다. 예: 사용자명 / 저장소명 / main.
3. GitHub에서 Fine-grained personal access token을 만들고 해당 저장소만 선택, Contents 권한을 Read and write로 설정합니다.
   토큰은 웹사이트 코드에 적지 마세요. 관리자 화면에 직접 입력하는 동안에만 사용되며 저장하지 않습니다.
4. [게시된 신규 작품 불러오기]를 누릅니다. 기존 4개 작품은 별도로 유지됩니다.
5. 제목과 유튜브 링크(또는 작은 영상 파일), 썸네일 파일을 넣고 [작품 목록에 추가 / 수정]을 누릅니다.
6. [GitHub에 게시하기]를 누르면 등록한 새 작품 목록이 GitHub에 반영됩니다. GitHub Pages 배포 완료 후 확인하세요.
7. 새 작품의 순서를 바꾸거나 수정/삭제할 수 있습니다. 기존 작품은 이 화면에서 건드리지 않습니다.

주의
- GitHub Pages는 공개 정적 사이트이므로 '숨겨진 비밀번호'를 HTML/JS 코드에 직접 넣으면 안전하지 않습니다.
- Ctrl+Alt+E는 관리자 페이지로 이동하는 편의 기능일 뿐 인증 기능이 아닙니다.
- 이 구현은 GitHub API를 브라우저에서 사용하므로, 신뢰할 수 있는 컴퓨터에서만 토큰을 입력하세요. 공개 PC 사용 금지.
- GitHub의 토큰 권한은 반드시 특정 저장소 Contents만 허용하고, 필요하면 즉시 폐기하세요.
- 동영상 파일 직접 업로드는 15 MB 이하로 제한합니다. 큰 영상은 유튜브에 올리고 링크를 등록하세요.
- 로컬에서 파일로 열면 JSON fetch가 작동하지 않을 수 있습니다. GitHub Pages에서 확인하세요.
- JSON 파일과 이미지/영상은 GitHub 저장소에 저장되며, 실제 공개 사이트에 반영되기까지 시간이 걸릴 수 있습니다.
