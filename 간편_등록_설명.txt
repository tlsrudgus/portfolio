간편 작품 등록 가이드
===================
1. premiere.html에서 Ctrl + Alt + E 누르기
2. 기본 비밀번호 1234 입력 (변경: js/simple-manager.js 맨 위 ADMIN_PASSWORD)
3. 마지막에 생긴 [+ 작품 추가] 카드 클릭
4. 제목, 썸네일, 동영상/이미지 파일 또는 유튜브/외부 링크 선택
5. 처음 게시할 때만 [GitHub 게시 연결] 열어서 계정명, 저장소명, 브랜치, Fine-grained GitHub 토큰 입력
6. [작품 등록하기] 클릭: 저장소 파일 업로드 및 목록 업데이트. GitHub Pages 배포 후 공개됨

참고
- 기존 4개 작품의 HTML은 변경하지 않았습니다.
- 신규 작품은 data/premiere-extra.json 목록에 추가됩니다.
- 관리 모드 단축키/비밀번호는 우연한 진입 방지용입니다. 실제 게시에는 GitHub 토큰이 필수입니다.
- GitHub 토큰은 코드나 localStorage에 저장하지 않으며 새로고침하면 다시 입력해야 합니다.
- 직접 업로드는 동영상 15MB, 이미지 8MB, 썸네일 5MB 제한입니다. 큰 동영상은 유튜브 링크 사용을 권장합니다.
- 신규 등록은 Premiere 페이지에 적용했습니다. 다른 작품 페이지는 기존대로 유지합니다.
- 기존 admin.html은 호환을 위해 보관했으며, 새 등록 화면은 Premiere 페이지 안에서 열립니다.
