프리미어 포트폴리오 관리자 모드 추가 안내

1. premiere.html 페이지에서 Ctrl + Alt + E를 누르고 비밀번호 1234를 입력합니다.
   비밀번호는 js/simple-manager.js 맨 위의 ADMIN_PASSWORD를 바꾸면 됩니다.
2. 기존 작품의 아래에는 [위치 조절] 버튼이, 새로 등록한 작품에는
   [위치 조절] [수정] [삭제] 버튼이 보입니다.
3. 위치 조절에서 가로/세로/크기 슬라이더를 변경한 후 GitHub 게시 정보를 입력하고 저장합니다.
4. 새 작품을 수정하려면 [수정]을 눌러 제목/링크를 바꾸거나 새 썸네일/파일을 선택합니다.
   교체하지 않는 썸네일과 파일은 비워 둘 수 있습니다.
5. [삭제]는 새로 추가한 작품에만 적용됩니다. 기존 HTML의 작품 4개는 보존됩니다.
6. GitHub Fine-grained 토큰은 'Contents: Read and write'와 해당 저장소 선택이 필요합니다.
   비밀번호는 관리자 화면 잠금용일 뿐 게시 권한을 부여하지 않습니다.

작품 목록: data/premiere-extra.json
기존 작품 위치: data/premiere-layout.json
추가 작품별 위치: data/premiere-extra.json의 position

* 새 작품을 목록에서 삭제해도 업로드한 media 파일은 보관됩니다.
* GitHub Pages 배포는 잠시 지연될 수 있습니다.
* 등록된 작품만 위치를 바꾸며 다른 작품의 값은 건드리지 않습니다.
* GitHub 연결 없이 버튼을 누르면 화면 미리보기만 가능합니다.
